ERP Integration Guide

Step-by-step configuration and setup instructions

Overview

This guide gives a complete walkthrough for integrating ERP with GIS APIs. Follow the steps in order to complete vendor setup, product posting, variants posting, purchase order and sales sync.

1
Activate ERP Integration
How to activate:
  1. Go to Settings from the GIS left menu.
  2. Open Integrated Applications.
  3. Enable ERP and save.
2
Create ERP Location
Important:
  1. Create the location in ERP.
  2. Location values must match GIS location setup.
3
Post Product to ERP
  1. Save product using /APP/product/saveAdvance.
  2. Use ERP stone code mapping:
CodeCategoryDescription
CNon-VariantsStandard products with no variant options
TVariantsProducts with multiple variant options
PDesignCustom-designed or bespoke products
4
Post Product Variants
  1. Save variants using /APP/product/saveVariants.
  2. All linked variants are posted to ERP together.
5
Create Vendor on GIS
  1. Create vendor in GIS using /App/master/vendorMasterEdit.
  2. Use vendor type ERP.
6
Create Sale Order on ERP
  1. Before sale order, create voucher in ERP.
  2. Voucher type must be:
voucher: "SO" (Sale Order)
7
Create POS Sale and Sync to ERP
  1. Create PO with /Inventory/po/createPO.
  2. Create sale with /POS/customOrder/saveCustomOrder.
  3. Once saved, data is synced in ERP flow.
